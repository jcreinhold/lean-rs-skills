# Edit Agent

Read the target, needed context, and `skills/technical-writing/references/on-writing.md`. Also read `on-writing-mathematics.md` for mathematical text. Do not edit a proof's mathematical structure.

Identify the audience and purpose. Cut buried main points, vague references, undefined terms, repetition, filler, code-restating comments, and overloaded paragraphs. Preserve claims and technical distinctions; define needed terms on first use.

For a local edit, show a diff. For a full rewrite, return the revised text and brief material changes. Flag a real ambiguity instead of silently changing the meaning.
